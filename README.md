## 🎯 Concept & Storytelling (4 Actes — 85s / 01:25)

L'expérience exploite le thème de la **« trajectoire »** sur deux plans complémentaires :
1. **Trajectoire technique** : Du contrôle des trajectoires aériennes dans les nuages (**Projet AMS**) à l'atterrissage sur le tarmac et la sécurisation des trajectoires passagers via les portiques biométriques (**Projet CABIS**).
2. **Trajectoire personnelle** : Le V.I.E comme accélérateur décisif de carrière, alliant la rigueur du savoir-faire français à l'agilité multiculturelle des ingénieurs roumains.

### Structure narrative conforme au barème (sur 10) :
- **Acte 01 // 30,000 FT (0s - 22s)** : *Promotion de la mission V.I.E* — Rapatriement et migration d'outils critiques de navigation aérienne (AMS), double casquette Full-Stack & Scrum Master.
- **Acte 02 // 4,500 FT (22s - 44s)** : *Découverte de la Roumanie & culture* — Plongée dans le hub tech de Bucarest, synergie d'équipe, accueil chaleureux et francophile.
- **Acte 03 // 0 FT / SOL (44s - 67s)** : *Mission V.I.E & Sûreté* — Sur le tarmac, transition vers les portiques biométriques aéroportuaires CABIS, architecture logicielle de bout en bout.
- **Acte 04 // PERSPECTIVES (67s - 85s)** : *Rayonnement du savoir-faire français & impact* — Union de l'excellence française et du dynamisme roumain, nouvelle trajectoire de vie.

## 🛠️ Stack Technique

- **Framework Web** : React 18 + TypeScript + Vite
- **Moteur 3D** : Three.js (WebGL, 60 FPS, rendu procédural 100% libre de droits)
- **Design System** : Tailwind CSS v4 + Lucide React + Glassmorphism HUD
- **Narration Audio** : Synthèse vocale neuronale française HD (`edge-tts`)
- **Pipeline Vidéo** : Capture automatisée Playwright + encodage H.264 / AAC via FFmpeg
